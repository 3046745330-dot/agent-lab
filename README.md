# agent-lab —— 手搓 Agent 内核

**这不是一个"让 AI 帮你做项目"的目录，这是一个"你自己写、我只负责提问和验收"的目录。**

## 为什么要这么干

你原来的模式：给我任务 → 我写完 → 你拿到成品 → 你不懂。

那个模式的问题不是"你偷懒"，是**它让你在面试里必输**。因为面试官问的不是"你做出来了吗"，而是：

- 为什么用 A 不用 B？
- 出问题时你怎么发现、怎么定位？
- 这个参数调大调小会发生什么？

这些问题，只有**亲手写过、亲手调过、亲手炸过**的人才答得上来。看别人写 100 遍也答不上来。

## 规则（四条，请认真遵守）

| # | 规则 | 为什么 |
|---|---|---|
| 1 | **讲义先读，作业自己写。** 我只给函数签名 + 输入输出 + 验收标准 | 你不是不会写，你是没试过 |
| 2 | **卡住 20 分钟以上才看参考实现。** 20 分钟内卡住是正常的，那是学习发生的地方 | 一卡就看的，等于没做 |
| 3 | **每课结束我要追问 3 个问题**，答不上来就重做 | 这就是技术面试 |
| 4 | **验收脚本必须跑过。** 我说"你做对了"不算，脚本说对才算 | 客观标准，防止我放水 |

## 用什么模型

`.env` 里配了两个，都是**最便宜的 flash 档**：

- 智谱 `glm-4-flash`（默认）—— 免费/极低价，够用
- 阿里 `qwen-flash`（备用）—— 换一家厂商验证"协议是通的，只是地址和参数名不同"

**为什么不用 DeepSeek？** 因为这两个 key 你账号里已经有、已经在用了，不用再充值。学协议用哪个厂商都一样——学完你就知道"换厂商只是换 URL 和字段名"。
